# ADR-001 — Milestone 0 design freeze (2026-10-15)

Status: **accepted**. Recorded during the repository audit; preserves the
decisions from SUVIX_PLAN.md §25 unless the project owner explicitly changes them.

## Context

Empty repository `SRogDev/suvix` (public), created 2026-10-15. Milestone 0 tasks:
inspect the repository (nothing to preserve — it was empty), verify package
configuration, Python versions, provider SDK documentation, and package naming.

## Audit results (2026-10-15)

- PyPI name `suvix`: available (404 on pypi.org/pypi/suvix/json).
- Toolchain: Python 3.12.3, uv 0.12.19, ffmpeg/ffprobe present locally.
- SDK versions recorded: `google-genai` 2.31.0, `openai` 3.31.0,
  `twelvelabs` 1.3.6, `streamlit` 1.66.0, `jsonschema` 4.26.0, `pydantic` 2.14.1.
- Provider doc hubs verified live: ai.google.dev/gemini-api/docs,
  openrouter.ai/docs, docs.twelvelabs.io. Per-adapter verification (§7.4 of the
  plan) happens when each adapter is implemented (M3, M7).

## Decisions

1. **Package manager: uv.** Deps in `pyproject.toml [project]`, `uv.lock`
   committed. src/ layout, hatchling build backend.
2. **Runtime floor: `requires-python >= 3.10`.** Modern enough for asyncio-based
   design, broad enough for downstream users.
3. **Minimal core dependencies: `pydantic` + `jsonschema`.** pydantic for typed
   public contracts; jsonschema for local Draft 2020-12 schema validation.
   No OpenCV, no numpy in the core — media metadata goes through ffprobe.
4. **Provider SDKs are optional extras** (`gemini`, `openrouter`, `twelvelabs`).
   The core must never import them; the dependency direction is one-directional.
5. **ffprobe/ffmpeg is an optional external dependency.** Detect its absence and
   raise a clear, actionable error. Do not vendor heavy media libraries for MVP.
6. **License default: MIT.** The plan specifies an open-source library but names
   no license; MIT is the owner's standard for portfolio showpieces and can be
   changed by the owner at any time.
7. **No cache, no database, no persistence** — architectural constraint, not a
   deferred feature. Temp files allowed with documented cleanup.
8. **Public API: async-first** (`Suvix.extract` is a coroutine). Blocking media
   work is offloaded to threads.
9. **Result contract**: `data` / `evidence` / `validation` / `usage` / `execution`
   as separate, typed fields (one modeling approach, chosen consistently in M1).
10. **Benchmark-first evaluation**: no cost or accuracy claims without measured
    baselines; negative results retained and reported.

## Consequences

- M1 (contracts + fake adapter) can proceed without any provider SDK installed.
- Media work (M2) must degrade gracefully when ffprobe is missing.
- Per-adapter doc verification records are created in M3 and M7, not here.
